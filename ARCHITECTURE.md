# Nexa Builder architecture roadmap

Nexa is designed as an extensible foundation:
- UI layer: builder, progress, preview, editor
- AI provider layer: Gemini model discovery + generation
- Artifact layer: generated site + future versions
- Action layer: export now; secure publishing later
- Agent layer: future tools and automation
- Voice layer: future STONIC integration

Keep voice, memory, tools and publishing separate from the website generator so they can evolve independently.
